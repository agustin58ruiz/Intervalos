# Intervalos

Entrenador de oído y lectura musical en una sola página (`index.html`, sin dependencias externas salvo las fuentes).

- **Practicar**: escuchá dos notas y adiviná el intervalo.
- **Aprender**: ficha de cada intervalo con canciones de referencia y un recorrido por pasos.
- **Notas**: leé la nota en el pentagrama (clave de Sol, Fa o ambas; sin alteraciones, con ♯/♭ o con armadura) y elegí entre cuatro opciones. Cada nota tiene una distribución Beta(α, β) de tu acierto y la próxima nota se elige por muestreo de Thompson, así las que te cuestan salen más.

Se publica en GitHub Pages con el workflow `.github/workflows/pages.yml`.
